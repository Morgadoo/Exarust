# Design

## Behaviour

A state other than zero runs the base with the key and flags and returns its result. Otherwise a set hide flag with the deadline at 0x220 less 0x3b6 still above the clock returns without work. With key flag 0x2 clear, a key equal to the global next code steps +1 and one equal to the previous code steps −1. Any other key dims unless the tree's 0x21d word carries 0x2.
