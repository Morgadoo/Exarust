# `exa_formats`

Engine-independent parsers for the formats inside the packs. Each takes
bytes and returns plain data or an error. No Bevy dependency.

**Phase:** 0–1. Spec and status per format: [`docs/formats/`](../../docs/formats/README.md).

| module | status |
|---|---|
| `kind` | format detection by magic for every shipped entry |
| `chunk` | `.rfc` chunk framing and list chunks |
| `rfi` | images: header, mip chain, BC1/3/4/5 + uncompressed decoding (through the `pixel` converters), RLE unpacking, the header flag word (stored chain, repeat per axis, the two-bit texture detail class) and the first uploaded mip level the detail setting picks |
| `palette` | the dye palette: 32 families (hue, saturation, base value, step), the linear and lifted HSV ramps and their linear-light colours |
| `procedural` | the 25 procedural materials: family, passes, colour/specular/normal texture lists and wear weight; the random material sets, finish levels, colour classes, default finishes and emblem ids |
| `pixel` | the original's 20 pixel formats (ids, fallbacks, sizes) and its converters between them: grey, alpha, grey-alpha, two-channel with Z rebuilt, 1-bit, RGB and RGBA sources, luma, the float formats; the byte/float conversions its mipmapper picks per format word (linear, squared colour, centred) |
| `rdb` | database index |
| `roles` | roles (`charroles.rdb`): head, init script, variables and entries with their sections (the corpse script where the original reads it), the dialogue graphs of role entries and `narrator.rcd`; a level's locale in `locales.rdb` |
| `races` | races: names, flag words (bleeding, red regeneration, claws, hovering, quadruped), body model, movesets, health, natural armour, the body scalars (clip-rate base, size, scale, mass divisor) and the body controller's factors, the gait table with its brake distances and the feral sprint blend, and the stats (unarmed reach, weapon swing-turn and recovery factors, AI attack bonus, perception, held offset, footsteps, voice) |
| `characters` | a level's placed characters (position, facing, condition, pose) and their records read whole, versions 5–7 (level databases and `actors.rpk`): looks (physique, height, age, skin, hair, face, voice number, pitch, sex, race), held and worn items with their flags, feral level, saved pools, seed, combat skill, undead voice, traits, search seed, experience, the six skills with their techniques, inventory, roles with their stored weights, relations and per-level relation tables, saved state, loadouts, the reserved words and powers; the record written back byte for byte (voice rebuilt from its number by the game's formatter, names one byte per character, traits converted as the game's SSE instruction does, five techniques at most, powers and the reserved pair only when set), copied through the writer, the constructor's and the creator's defaults (focus 0; the reset also in place, with the underwear), the record's own technique check, the perks the learnt techniques give, the Manoeuvring tier and Deflection; an actor's own item database |
| `character_stats` | the stats a record and its race spawn with, as the original's builder and init derive them: body scale and size by height, standing pelvis, leg reach, most energy, step reach, support pins' factor, the undead's head gain and factor and walking arms, sprint gait, perception, voice, maximum health with the race-byte rules, health from the saved pools (in double precision), the body rule bits; Deflection and the encumbrance the armour pass sums |
| `encumbrance` | a character's encumbrance as the original's armour pass sums it (worn items' bytes, articulated pieces, Manoeuvring tiers, the floor, the held shield with Mobility, the golem suit, the cap) from a record and the databases its ids name, and the factors it gives the reach, run, sprint, turn, steps and get-up clock |
| `rfc` | scene nodes (meshes, lights, voxel lights; box, rigid body, cloth marker, the static node flag, keyframe tracks after any kind's body, a mesh's morph set) and static meshes with their position-stream count and smoothing keys (all retail meshes decode) |
| `rfc_write` | the original's level export: chunk framing (open, close, take back out), the walk that sorts and numbers nodes, props, placed objects and characters, and every chunk it writes (grid, materials with the texture renames, nodes with mesh, light, voxel light, rigid body, cloth, emitter, GI points and keyframe tracks, props and part records, the local database, characters with pose, AI home and motion state, environment); the save game's placement writer |
| `morph` | morph sets (`*morph.rfc`: landmarks, base positions, targets; both shipped sets decode), the physique weights a record gives them, the transfer to body parts and garments (nearest surface within 10 cm, the nearest landmark's offset, neighbour fill) and morphing a scene's meshes, bounds and joints |
| `key_track` | node keyframe tracks (`0x3AC1`): play mode, duration, keys of time and position (the one shipped track decodes) |
| `rigid_body` | models' rigid bodies: class, mobility, rest tetrahedron, point masses, collision spheres, links (pins, ropes, sliders with their travel), scrape and roll sound slots (every body of every pack decodes) |
| `material` | material payloads: shading parameters, texture layers and slot roles, the texture load flags (`0x54`), the subsurface colour (`0x6C`), the physical divisor a rigid body's mobility is divided by and the impact sound prefix |
| `objdb` | the object database: each tier held as the original's table over one payload blob (binary search and insertion, payload store and deletion, the writer, so a loaded database writes back byte for byte), the upgrade of the `0xDBAC0D08`/`0D07` layouts (operative and weapon converters), the section chain and its editing routines, table flags, the three id tiers with tagged lookup and first-free ids, header and model fields, the string resolver (none, inherit the parent's, an own tier string or the shared library), the template clone, instancing, local duplication, the item dispatcher, promotion to the world tier with container children and the id and link remap tables, both removal routines, template migration (body, appearance with the material sets, condition refresh of protection and value, weapon, container, door, model), the item-use test, the random-table condition word, the quantised item fields and the amount helpers; and the decoded item fields: names, models, occupancy, appearance, protection, burden (encumbrance, covered bones, articulated set, special kind, powered), the equip lock the conflict pass reads, weapon, shield, door and operative sections (including a teleporter's symbol atlas and destination level ids), and the mechanism a record makes of its model |
| `objstrings` | the object string library (`objstrings.rdb`, a level's `0xDBCD` library): one-based ids, reference counts, Latin-1 text, the original's allocator (free hint), setter (in place or hole closed and appended), add-reference and release, and the writer (byte for byte) |
| `trade_record` | the shop fields of an item record: listing word, parent id, the model's rarity tier, rarity and size words, and the rank by body, weapon or shield ([Trade fields](../../docs/formats/OTHER.md#trade-fields)) |
| `weapon_stats` | weapon stat bytes and how a factory recipe and the item's condition produce them (roles 1, 2, 4, 5 and 6, the actual deform curve, byte wrapping and caps) |
| `weapon_record` | the record a held weapon fights with (all 28 elements, the holding pass and the equip refresh), its length along the model's rigid parts, the built-in fists and claws by race, the race's weapon fields from its decoded stats, the mass table, the shield record and the step reach |
| `rsq` | skeleton, bodies and motion set of `humanoid.rsq`; the moveset tree (parents are the nearest earlier moveset of their name) and a character's clip table from a base moveset and the held items' config word (`MotionSet::assemble`, `MovesetConfig`: the weapon moveset under each ancestor, then the Torch and Flaming overlays) |
| `hw_config` | the hardware configuration: the settings screen's graphics, audio and input options with their ranges, defaults, slider steps and labels, the GPU benchmark's measurement protocol and quality tiers, the Deck preset, the settings file lines Apply writes, key names and the hardware startup settings ([UI.md](../../docs/UI.md#settings-options), [SETTINGS.md](../../docs/formats/SETTINGS.md#the-settings-screens-options)) |
| `settings_ini` | the user settings file: the registry of 41 named, typed settings, the `Name = value` reader with its conversions (integer, boolean, fraction, RGB/RGBA colour), the graphics, window and hardware rules and defaults (GUI size, quality clamps, frame cap, the aim-speed step, volume and the game's tips and checkpoints), the `KeyDef` hotkey macros, the settings screen's and the game's line rewriters, the number formats and the user folder and file names |
| `settings_store` | the binary settings store: nested `{tag, size}` chunks addressed by tag paths, get, set with the enclosing sizes kept, the integrity check and the empty-store rule; the key bindings' path |
| `save_package` | the retail save package: magic, sentinel and 24-byte directory, `0x2000`-aligned 16-byte-named sections with the original's placement (last strictly larger gap after any entry, the sentinel included; moved when the room is short; offset recomputed from the entry before on every write) and directory-only delete, the slot file names and scanner number, the 52-byte story/arena `#playerdata` headers, the character placement (reference, position, heading, condition, sub-chunks), tagged chunks, masks, journal, world database sections and version rules |
| `save_chunk` | the save game's settings chunk and the save curve, the version gate and record table, the save number, the mode words, the slot order/number/insert/delete rules, the permadeath (health below 0.01 in double) and checkpoint rules, and the game clock (signed tick difference) |
| `data_stream` | the engine's byte stream: writes that cut the size at the cursor and grow in 512-byte steps, u8/u16/u32/f32, text lines, length-prefixed strings, Latin-1 text as UTF-8 and back |
| `file_ref` | file plumbing: the folder table, file references with inline names, entry stems, extension swaps, the folders made for a path, the search path, whole-file reads and writes, and the file-format registry |
| `factory` | `.fty` weapon recipes (v0–v2): parts, deforms, variants and tags; the four generation paths (full roll, stored replay, freshly stored replay, initial choice store), area material/finish/colour and emblem rolls, component placement and the five mesh deforms |
| levels, terrain, actors, powers | Phase 1 |
